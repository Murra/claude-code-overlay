## screenshot.png

A genuine screen capture, not a mockup, cropped to the taskbar and composited with a ~1.8x
detail view because the panel is only 262x40 px and would otherwise be illegible at README
width. The window above the taskbar was cropped away.

Anything captured from a real desktop ends up public, so check the full-resolution pixels
before replacing this: magnify the icon cluster and the system tray and confirm no window
titles, file names, notification text or account details are readable. The current image shows
only application icons, a keyboard-layout indicator and the clock.

## thresholds.png

Generated by rendering the real `OverlayWindow` at each state and calling `QWidget.grab()`, so
it cannot drift from what the app draws. Re-render it rather than editing it by hand after a
layout or palette change. The widget renders at the display's device pixel ratio, so a 2x
screen produces 524x80 images for a 262x40 window.
